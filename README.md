# 業務共有アプリ

秘書さんとオンラインで業務（物品購入・国内出張・国外出張・その他）の進み具合を共有するための Web アプリです。
ビルド不要の静的サイト（HTML / CSS / JavaScript）なので、GitHub にアップロードするだけで公開できます。

## 仕組み

- **アプリ本体**は GitHub Pages で公開します（このフォルダの中身）。
- **入力したデータと添付ファイル**は、アプリ本体とは別の場所に保存します。そのため、仕様を追加してアプリを再アップロードしても入力済みのデータは失われません。
- 保存先は次の 2 方式から選べます。**標準は Google Drive 方式**です。

| 方式 | 利用者に必要なもの | 保存先 |
|---|---|---|
| **Google Drive（Apps Script 経由）** 推奨 | 共通パスワードを設定画面に一度入力するだけ | 先生の Google Drive の「業務共有データ」フォルダ |
| GitHub リポジトリ（上級者向け） | 利用者ごとに GitHub アカウントとアクセストークン | プライベートリポジトリ |

```
アプリ用リポジトリ（GitHub Pages で公開）      Google Drive（先生のアカウント）
├─ index.html                               └─ 業務共有データ/
├─ config.js                                    ├─ gyomu-data.json   … 設定・プロジェクト
├─ css/style.css                                └─ files/<プロジェクトID>/… … 添付ファイル
├─ js/…
└─ gas/Code.gs  … Apps Script に貼り付けるコード（アプリからは読み込まれません）
```

## 初回セットアップ（Google Drive 方式）

### 1. Apps Script を公開する（先生が 1 回だけ行います）

1. Google アカウントでログインした状態で https://script.google.com/ を開き、「新しいプロジェクト」を押す。
2. エディタに最初から入っている内容をすべて消し、`gas/Code.gs` の中身を貼り付ける。
3. 上のほうにある次の行を、好きなパスワードに書き換える（半角英数字を推奨）。
   ```js
   const PASSWORD = 'ここに好きなパスワードを設定してください';
   ```
4. 左上の「無題のプロジェクト」をクリックして名前を付ける（例: 業務共有）。Ctrl+S で保存。
5. 右上の「デプロイ」→「新しいデプロイ」→ 左の歯車から種類「**ウェブアプリ**」を選ぶ。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
6. 「デプロイ」を押す。初回は「アクセスを承認」を求められるので、自分のアカウントを選び、
   「このアプリは Google で確認されていません」と出たら「詳細」→「業務共有（安全ではないページ）に移動」→「許可」を押す
   （自分で作ったスクリプトに Drive へのアクセスを許可する操作です）。
7. 表示された「**ウェブアプリ**」の URL（`https://script.google.com/macros/s/.../exec`）をコピーしておく。

大学の Google Workspace で「アクセスできるユーザー」に「全員」が選べない場合は、個人の Google アカウントで同じ手順を行ってください。

### 2. アプリ用リポジトリを作って公開する

1. GitHub で「New repository」からリポジトリ（例: `gyomu-app`）を作る。Public で構いません（アプリ本体にはデータもパスワードも含まれません）。
   Private にする場合、GitHub Pages を使うには GitHub Pro / Team などの有料プランが必要です。
2. （任意）`config.js` の `gasUrl` に手順 1 でコピーした URL を書いておくと、設定画面に最初から入力された状態になります。パスワードは書かないでください。
3. 「Add file → Upload files」で、このフォルダの `index.html`, `config.js`, `README.md`, `css` フォルダ, `js` フォルダ をドラッグ＆ドロップして「Commit changes」。
4. Settings → Pages → Build and deployment で **Source: Deploy from a branch**、Branch: `main` / `/(root)` を選んで保存する。
5. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリが開けます。

### 3. アプリに接続する（利用者ごと・ブラウザごとに 1 回）

1. 公開した URL を開き、右上の「⚙ 設定」を開く。
2. 「Google Drive に保存」を選び、Web アプリの URL と共通パスワードを入力する。
3. 「接続テスト」で「接続できます」と表示されたら「保存して接続」を押す。
4. 設定画面の下で「予算の選択肢」を登録する（物品購入・国内出張・国外出張で共通）。必要ならチェック項目のテンプレートも編集する。

秘書さんには、アプリの URL と共通パスワードを伝えるだけです。Google アカウントも GitHub アカウントも不要です。

## 使い方

- 上部のタブでカテゴリ（物品購入 / 国内出張 / 国外出張 / その他）を切り替え、「新しいプロジェクト名」を入れて **作成** します。
- プロジェクトを開くと、カテゴリごとのテンプレートに沿ったタブ（例: 申請時 / 終了後）とチェック項目が並びます。
  - 入力すると自動的に保存されます（右上に「保存済み」と表示されます）。
  - 項目名はクリックして書き換えられます。↑↓ で並べ替え、× で削除、下の欄から項目を追加できます。
  - タブも「＋」で追加、名前変更、削除ができます。
  - 「メモ・連絡事項」欄は自由記入です。
- 各項目は種類ごとに完了条件が決まっており、完了すると緑のチェックが付きます。

| 種類 | 完了の条件 |
|---|---|
| チェック | チェックを入れる |
| 有 / 無 | 「有」か「無」のどちらかが選ばれている（法人カード利用など） |
| 短文入力 / 長文入力 | 何か入力されている |
| 日程（出発日・帰学日・日帰り） | 出発日があり、帰学日があるか「日帰り」がチェックされている |
| 日程（出発日・帰学日） | 出発日と帰学日の両方がある |
| 予算（選択） | 選択肢から選ばれている |
| ファイル添付 | 1つ以上ファイルがある |
| ファイル添付 または 現物提出 | ファイルがあるか「現物提出済み」がチェックされている |
| 終了 または 不要 | 「終了」か「不要」が選ばれている |

- 「✓ 完了にする」でプロジェクトを完了扱いにできます（一覧の「完了」フィルタで表示）。
- 添付ファイルはファイル名をクリックするとダウンロードされます。Google Drive 方式では 1 ファイル 20 MB までです。
  添付ファイルは先生の Google Drive の「業務共有データ/files」にも実ファイルとして残ります。
- 相手の入力を反映したいときは右上の「↻ 更新」を押します（ウィンドウを切り替えて戻ったときも自動で読み直します）。

## アプリを更新するとき

アプリ用リポジトリのファイル（`index.html`, `js/…` など）を上書きアップロードするだけです。
データは Google Drive 側にあるので、入力済みの情報・添付ファイルはそのまま残ります。
Apps Script 側（`gas/Code.gs`）を変更した場合だけ、Apps Script のエディタで「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」を行ってください（URL は変わりません）。

## パスワードを変えたいとき

Apps Script のエディタで `PASSWORD` の行を書き換えて保存し、上記の「デプロイを管理」から新バージョンをデプロイします。各利用者は設定画面で新しいパスワードを入力し直します。

## 注意事項

- お試し用に「このブラウザの中だけに保存」モードがあります。このモードでは共有されず、ブラウザのデータを消すと失われます。
- 2 人が同じプロジェクトを同時に編集した場合、後から保存した側が相手の最新版を読み込み、自分が変更した項目だけを重ねて保存します。項目の追加・削除・並べ替えが重なった場合はその操作が反映されないことがあるので、画面の通知に従って確認してください。
- 共通パスワードを知っている人は誰でもデータを読み書きできます。パスワードは推測されにくいものにし、関係者以外に共有しないでください。
- Apps Script の応答には 1〜2 秒かかることがあります。保存は自動で行われるので、画面右上の表示が「保存済み」になるのを確認してから閉じてください。

## 付録: GitHub リポジトリ方式（上級者向け）

Google Drive を使わず、データを GitHub のプライベートリポジトリに保存する方式です。利用者ごとに GitHub アカウントとアクセストークンが必要になります。

1. データ用のプライベートリポジトリ（例: `gyomu-data`）を「Add a README file」にチェックを入れて作成し、共有相手を Settings → Collaborators から **Write** 権限で追加する。
2. 各利用者は GitHub の Settings → Developer settings → Personal access tokens → **Fine-grained tokens** でトークンを作る。
   Repository access は「Only select repositories」でデータ用リポジトリだけを選び、Permissions → Contents を **Read and write** にする。
3. アプリの設定画面で「GitHub リポジトリに保存」を選び、オーナー、リポジトリ名、ブランチ（`main`）、トークンを入力して「保存して接続」。
4. トークンはこのブラウザ内にのみ保存され、GitHub 以外には送信されません。期限が切れたら作り直して入れ替えてください。1 ファイル 50 MB まで添付できます。
